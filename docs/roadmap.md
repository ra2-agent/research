# 研究路线

## 第一阶段：可复现的基线

公开含 ra-arena 的引擎提交，冻结协议与规则，收录最小基线、启发式基线和社区策略。使用镜像局与未参与调参的种子验收，分别记录运营与作战表现。

## 第二阶段：策略迭代

优先研究建造队列竞争、资金预留、矿场/矿车配置、生产队列深度、兵种组合、集火、撤退与残局处理。每项改动写清假设，保持共同引擎不变，避免把底层引擎变化归因于策略。

## 第三阶段：扩大评测条件

加入复杂地形、更多阵营、真实规则、视野过滤与明确的思考预算。协议或环境变化时独立开赛季，分别评估泛化与稳定性。

## 后续提案

进程隔离、跨语言、LLM Agent、原版游戏与不同模组赛道。先明确接口、合法数据来源、公平预算与复现方法，再实现。当前仓库没有承诺这些功能已可用。
